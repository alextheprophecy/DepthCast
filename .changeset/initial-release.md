Initial v0.1 release: image → automatic in-browser depth (Depth Anything V2, WebGPU→WASM) → interactive 3D pop-out via a dependency-free WebGL2 displacement renderer. Includes `feather` and push–pull `inpaint` occlusion handling, pointer/gyro/scroll/orbit controls, damped camera loops, WebM export, an SSR-safe `<Depth3D />` React wrapper, and a `precompute` CLI for shipping baked depth maps in production.
